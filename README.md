# 🧙‍♂️ Desafio DIO - Classes de um Jogo

Este projeto foi desenvolvido como parte do **Desafio da DIO** para praticar conceitos de **JavaScript** como variáveis, operadores, laços de repetição, estruturas de decisão, funções, classes e objetos.

---

## 🎯 Objetivo

Criar uma classe genérica que represente um herói de uma aventura com as seguintes propriedades:

- **nome**
- **idade**
- **tipo** (ex: guerreiro, mago, monge, ninja)
